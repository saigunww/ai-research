# 行知学园 · AI 科研背景提升

公开网站：https://ai-research.coach-ai-assist.com/

单页网站提供研究方向目录、科研实践路径、升学申请中的经历表达、官方大学招生要求动态、合格成果和咨询方式，支持简体中文、繁体中文、日语与英语。

## 内容维护

- `index.html`：页面结构与默认中文内容。
- `assets/site.css`、`assets/site.js`：视觉样式、四语言文案、目录搜索及分类。
- `data/catalog.json`：经过人工审核的公开目录及录取结果，仅包含明确允许公开的字段。
- `data/admissions.json`：大学官方要求的适用项目、通道、摘要、来源及最近核对状态。
- `images/`：网站使用的品牌标识、咨询二维码与用户指定公开的两张何同学合格榜。
- `campus.html`、`ai-research.html`：旧链接兼容入口，跳转到新首页；不再提供大学项目页面。

目录按实际资料汇总为领域概览，不公开具体研究设计。`practice` 表示有研究实践记录，`pilot` 表示试点探索，`proposal` 表示方向储备；这些状态不表示学生完成情况。自动同步只使用经过审核的四语概览，追踪对应资料变化，并在配置的正式运行满足强证据条件时提升阶段。新出现、尚未归类的方向写入私人待审记录，不能把原文件名或正文直接发布。

合格成果按学校计数，同一学生获得多校录取时分别展示。2026 年 11 月 12 日核对的两项记录，均为何同学的 2027 年度学部录取。

公开文件中不得加入学生志望理由书、完整姓名、内部路径、实验方案或具体课题研究材料。升学应用板块只提供通用表达建议，官方要求板块可以介绍材料名称。依用户明确要求，合格成果使用已将姓名打码的原合格榜；图中保留已有课题标题、受验号和语言成绩，不应据此推导或补充内部材料。大学院网站已公开且归入 AI 分类的新海报自动同步；高清原图须与公开记录的 SHA-256 匹配。内部审核记录与备份存放在仓库外，不提交 Git。

## 自动更新

服务器用户服务 `ai-research-update.timer` 每小时日本时间 **40 分左右**运行，通常在上游合格榜任务之后；机器恢复运行时补做漏过的一次检查。只读取服务器资料，不启动训练或改变实验文件。

同步内容：

- 课题：读取仓库外的批准目录配置，追踪来源变动，更新公开日期和经强证据确认的阶段。新方向完成脱敏归类后，下次运行自动上线。
- 合格：复用大学院网站的公开 `honors_data.json`，仅导入 `ai-research`，保留匿名学生称呼、已有四语言详情和高清图。缺图、缺字段或上游异常时保留已发条目。
- 官方要求：每小时检查已核验的大学页面及相关 PDF。正文变化时标记“官网有更新”，提示核对最新要求；不会把旧摘要当作已确认的新规定。经人工核对新版本后更新摘要及批准版本。连接失败保留上次数据并显示检查失败状态。这是按小时监测，不是大学网站的秒级推送。

`scripts/sync_and_publish.py` 默认生成私人预览；加 `--publish` 才提交、推送并同步本地网页副本。只允许提交两个公共 JSON 和受管理的合格图片。脏工作区、未发布手工提交或远端分叉会停止本次发布，不覆盖用户改动。自动提交带有本机私人凭证，推送失败后可核验并重试。

私人配置和状态放在仓库上级的 `自动更新/`：`topic_sources.private.json`、`sources.private.json`、`admissions_sources.private.json`；状态、待审记录及错误信息也保留在那里，不能提交到公共仓库。PDF 抓取依赖系统 `pdftotext`，Python 依赖见 `requirements-sync.txt`。

## 本地预览与发布

在仓库目录运行 `python3 -m http.server 8080`，通过 `http://localhost:8080/` 查看。页面会请求 JSON 目录，应通过 HTTP 服务预览。

提交前检查四种语言、分类搜索、移动端、旧链接跳转、资源加载以及公开数据字段。提交至 `main` 后由 GitHub Pages 发布，并核对线上 HTML、样式、脚本与目录文件。
