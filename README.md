# 行知学园 · 科研背景提升

公开网站：https://ai-research.coach-ai-assist.com/

分页网站提供研究方向目录、科研实践路径、升学申请中的经历表达、官方大学招生要求动态、合格成果和咨询方式，支持简体中文、繁体中文、日语与英语。

## 内容维护

- `index.html`：简洁首页与各栏目入口。
- `topics.html`、`practice.html`、`programs.html`、`applications.html`、`admissions.html`、`honors.html`、`contact.html`：独立栏目页面；共同使用四语脚本与样式。旧首页栏目锚点自动跳转到对应页面，跨页链接保留语言。
- `assets/site.css`、`assets/site.js`：视觉样式、四语言文案、目录搜索及分类。
- 首页首屏以服务器、AI研究室门面、何同学科研学习、金同学细胞培养、马同学发表练习、赵同学英语发表练习六张实拍照片作循环背景；每2秒自动切换下一张，淡入淡出，可前后切换、点选或暂停。原子图及生命科学、化学与材料、智能计算、人文与社会、经济与经营五个专业标签悬浮在照片上方，电脑置于左侧文案下方，避开人物区域；手机置于照片顶部。`assets/hero-carousel.css`、`assets/hero-carousel.js` 仅在首页加载，沿用四语切换，页面隐藏时暂停，减少动态效果偏好下默认静止；图片失败会跳过，不影响标题和导航。
- `data/catalog.json`：经来源核对、四语整理和字段校验的课题目录及录取结果。
- `data/admissions.json`：大学官方要求的适用项目、通道、摘要、来源及最近核对状态。
- `images/`：网站使用的品牌标识、咨询二维码与用户指定公开的两张何同学合格榜。
- `images/practice/`：用户指定公开的 GPU 服务器、何同学学习背影、金同学细胞培养、马同学发表练习及赵同学英语发表练习照片的网页编码版本；原素材与来源记录保留在仓库外的资料库中。
- `images/hero/`：AI研究室门面原片的响应式 WebP 副本；与 `images/practice/` 的既有实拍照片共同用于首页背景，原片不改写，网页副本移除拍摄元数据。
- 项目方案：按现有宣传册介绍基础档、成果档、专业档及私人定制，展示人群、内容与成果，不列价格。四档内容及照片说明均提供四语。
- `campus.html`、`ai-research.html`：旧链接兼容入口，跳转到新首页；不再提供大学项目页面。

目录覆盖服务器科研项目、教学课题及科研提案中有实质内容的研究主题。同一方向的不同格式和版本合并，有独立研究问题的课题分别展示。页面统一提供课题名称、研究概要、类别和关键词，不显示提案、试点或实践阶段标签，也不把研究方向表述为已经完成的成果。内部阶段字段只用于来源管理，不能据此推断学生完成情况。原始文件、姓名、内部路径和具体实验设计不进入公开目录。

合格成果按学校计数，同一学生获得多校录取时分别展示。2026 年 11 月 12 日核对的两项记录，均为何同学的 2027 年度学部录取。

公开文件中不得加入学生志望理由书、完整姓名、内部路径、实验方案或具体课题研究材料。升学应用板块只提供通用表达建议，官方要求板块可以介绍材料名称。依用户明确要求，合格成果使用已将姓名打码的原合格榜；图中保留已有课题标题、受验号和语言成绩，不应据此推导或补充内部材料。大学院网站已公开且归入 AI 分类的新海报自动同步；高清原图须与公开记录的 SHA-256 匹配。内部审核记录与备份存放在仓库外，不提交 Git。

## 自动更新

服务器用户服务 `ai-research-topic-discovery.timer` 每天日本时间 **09:10 左右**检查科研项目、教学和科研提案目录，发现新增或变化的资料后归纳课题并更新网页。`ai-research-update.timer` 继续每小时日本时间 **40 分左右**同步现有目录、合格榜和招生信息，通常在上游合格榜任务之后；两个任务均会在机器恢复运行时补做漏过的检查。只读取服务器资料，不启动训练或改变实验文件。

同步内容：

- 课题：`scripts/discover_topics.py` 每日扫描指定的三个研究资料目录，跳过数据、模型、依赖、归档及非研究材料。变化资料经现有 Codex 登录以无工具、只读方式归纳为四语课题摘要；每条必须对应实际扫描来源，通过分类、翻译完整性、隐私和状态措辞校验后自动并入私人目录配置，再调用既有发布流程。无需另行人工添加新课题。重复版本沿用原课题 ID，已发布条目不自动删除；生成、来源读取或校验失败时保留现有网站，留存私人错误记录。小时任务继续追踪已登记课题的来源变化。
- 合格：复用大学院网站的公开 `honors_data.json`，仅导入 `ai-research`，保留匿名学生称呼、已有四语言详情和高清图。缺图、缺字段或上游异常时保留已发条目。
- 官方要求：每小时检查已核验的大学页面及相关 PDF。正文变化时标记“官网有更新”，提示核对最新要求；不会把旧摘要当作已确认的新规定。经人工核对新版本后更新摘要及批准版本。连接失败保留上次数据并显示检查失败状态。这是按小时监测，不是大学网站的秒级推送。

`scripts/sync_and_publish.py` 默认生成私人预览；加 `--publish` 才提交、推送并同步本地网页副本。只允许提交两个公共 JSON 和受管理的合格图片。脏工作区、未发布手工提交或远端分叉会停止本次发布，不覆盖用户改动。自动提交带有本机私人凭证，推送失败后可核验并重试。

私人配置和状态放在仓库上级的 `自动更新/`：`topic_sources.private.json`、`sources.private.json`、`admissions_sources.private.json`；每日扫描状态、归纳输入输出、配置旧版、待处理来源及错误信息也保留在那里，不能提交到公共仓库。PDF 抓取依赖系统 `pdftotext`，Python 依赖见 `requirements-sync.txt`。每日归纳复用服务器已有 Codex 登录，不把凭据写进仓库或系统服务参数。

日常运行与检查：

```bash
/home/admin-coach-ai/Documents/官网主页/大学院生化网页/.sync-venv/bin/python scripts/discover_topics.py --publish
systemctl --user status ai-research-topic-discovery.timer
systemctl --user status ai-research-update.timer
```

上面的 Python 命令从本仓库执行。首次已经逐项核对的资料可以用 `--baseline-reviewed` 记录基线；未映射的研究来源会阻止建立基线。之后任何新增来源、文档新增或文档变化都会触发新的归纳，文件 SHA256 可识别保留原时间戳的内容修改。源码修改后的验证使用上述环境的 `python -m unittest discover -s tests`，再检查四语搜索、分类和手机布局。

## 本地预览与发布

在仓库目录运行 `python3 -m http.server 8080`，通过 `http://localhost:8080/` 查看。页面会请求 JSON 目录，应通过 HTTP 服务预览。

提交前检查四种语言、分类搜索、移动端、旧链接跳转、资源加载以及公开数据字段。提交至 `main` 后由 GitHub Pages 发布，并核对线上 HTML、样式、脚本与目录文件。
